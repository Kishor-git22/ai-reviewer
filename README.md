# Prism Web (ai-reviewer-web) 💎

The frontend for **Prism**, an open-source AI code review platform. Prism takes a single Pull Request and refracts it through three different AI models to provide a high-confidence, multi-perspective analysis.

## 🚀 Overview
- **Landing Page**: Real-time stats and an interactive 3D hero section.
- **Dashboard**: Deep-dive analysis of AI findings, grouped by severity and consensus.
- **User Control**: Custom model selection (pick 3 of 6) and absolute data privacy.

## 🛠 Tech Stack
- **Framework**: [Next.js 15](https://nextjs.org/) (App Router)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/) + [shadcn/ui](https://ui.shadcn.com/)
- **Auth**: [NextAuth.js v5](https://authjs.dev/) (GitHub Provider)
- **Data Fetching**: [TanStack Query v5](https://tanstack.com/query/latest)
- **Visuals**: [React Three Fiber](https://docs.pmnd.rs/react-three-fiber/getting-started/introduction)
